# Cálculo de Tablas de Reparto

## Descripción

Aplicación desarrollada en Python para calcular automáticamente el reparto de pedidos entre clasificadores, respetando todas las reglas de negocio del almacén.

---

# Objetivos

- Automatizar el cálculo del reparto.
- Reducir la intervención manual.
- Mantener el equilibrio entre clasificadores.
- Facilitar futuras ampliaciones.

---

# Tecnologías

- Python
- SQLite
- Visual Studio Code
- Git
